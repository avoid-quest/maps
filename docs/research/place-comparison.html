Place-search validation

Separate source-data coverage from retrieval and interface behavior.

LayerCheckInterpretation
Source dataRecord present with usable name, category and addressMissing source records require independent data or a verified correction
Package and indexSource record reaches the installed packageOld data or indexing can hide an existing place
Query and rankingExact-name and category queries retrieve the correct branchAliases, categories, viewport and ranking affect discoverability
Place detailsEntrance, status and contact fields have supporting evidenceUnknown hours and stale fields must remain visible as uncertain

Provider hit counts do not establish complete coverage. Operating status is not an opening-hours schedule.
