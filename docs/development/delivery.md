# Android build verification

## Current release line: 0.1.9

Version **0.1.9 / Android code 11** combines compact map-first UI, stable task/navigation geometry, foreground location acquisition and read-only provider diagnostics. Navigation still uses its existing GPS source and 20 m / 10 s acceptance policy. The production launcher exclusion keeps Google barcode-scanner dependencies out of the runtime graph while the separate development client remains available.

The signed APK, checksums, matching third-party source archive and exact artifact validation belong to the [0.1.9 release record](https://github.com/avoid-quest/maps/releases/tag/v0.1.9). Source/browser checks do not establish physical navigation, audible voice, screen-off operation, Android keyboard/accessibility or upgrade preservation. Run the acceptance checks in [android.md](android.md) and [navigation.md](navigation.md) for those boundaries.

Version [0.1.8](https://github.com/avoid-quest/maps/releases/tag/v0.1.8) already delivered native navigation and its matching source archive. Earlier observations below describe their named artifacts and are historical; statements that navigation or source publication was pending do not describe current delivery status.

## Native evidence and checks outstanding

On 2026-10-11, a Google-free AOSP API 36 x86_64 software emulator booted and installed the separately audited 0.1.2/code 3 APK. The installed version was confirmed; the Google Play services package was absent. With Metro stopped and no ADB reverse mappings, a cold ActivityManager launch exited successfully with `Status: ok`.

A usable screenshot showed the app's Italian main interface beneath Android's “Process system isn't responding” dialog; the map stayed gray/loading. This confirms bundled JavaScript rendered the main UI. The system-process ANR prevented healthy interaction checks, and the final UI-hierarchy capture timed out. Its root cause was not established. The older 0.1.0/code 1 install attempt timed out and supplies no accepted baseline or upgrade evidence.

Native discovery preference/coverage behavior, compact-package startup/search/memory, transit UI, keyboard/TalkBack, map rendering, diagnostics preview/copy/off/clear, permission denial and location acquisition, lifecycle recovery, force-stop saved-travel persistence and physical same-key upgrade preservation remain unverified. The older emulator launch does not validate these controls or the released 0.1.6 package. Use the acceptance list in [android.md](android.md) and [data preparation](data.md); physical-device GPS accuracy, approximate permission behavior and battery use require separate device evidence. Development 0.1.8 integrates a native location foreground service, Ferrostar road guidance, offline Italian TTS and manual transit transitions. Module compilation and JVM policy/transition tests pass; the integrated engine/JNA/GPS/TTS/service has not run on a usable Android runtime. Follow [navigation acceptance](navigation.md) for mode-specific journeys and screen-off/lifecycle checks. The production browser notice viewer passed offline-text checks with fetch blocked at 320 and 390 pixels for Ferrostar BSD, desugared OpenJDK GPL/exception and UniFFI MPL content, with zero fetches and no horizontal overflow. Final signed-artifact bundling, notice presence and native alignment remain separate inspection gates.

The prepared navigation source archive contains complete official desugared OpenJDK 2.1.5/Ferrostar 0.57.0 source and the nine unmodified MPL-2.0 UniFFI crates. Its notice hashes/component references, source version/build inputs and private-path/declaration/signing-content audit passed; generic OpenJDK key-store API/resource/test terminology was confirmed verbatim upstream source. Source delivery remains pending until the archive and checksum are published alongside the matching APK from the same release location. Publisher bit-for-bit rebuild and binary-to-source equivalence are not established. Private QA logs/screenshots stay outside Git and public reports.

## Artifacts

The build script produces `artifacts/avoid-maps.apk` and its SHA-256 companion. Build outputs and signing secrets are excluded from Git. Publish only inspected arm64 artifacts in [releases](https://github.com/avoid-quest/maps/releases); x86_64 builds are emulator artifacts. Release version and checksum identify the inspected download.
